# アナログ時計 (Analog Clock for Windows)

Visual Studio 2022 / C++ (Win32 API + GDI+) で開発されたデスクトップ用アナログ時計アプリケーションです。

---

## 🌟 主な機能・仕様

1. **時計の大きさを変更可能**
   - **マウスドラッグによるリサイズ**: ウィンドウ端（外周）にマウスカーソルを合わせるとサイズ変更カーソルに変わり、直感的にリサイズできます（縦横比 1:1 を自動維持）。
   - **マウスホイールによるリサイズ**: 時計上でマウスホイールを回転させると、時計の中心位置を保ったままスムーズに拡大・縮小できます。
   - **プリセットサイズ**: 右クリックメニューの「サイズプリセット」から「小 (160px)」「中 (240px)」「大 (360px)」「特大 (480px)」をワンクリックで選択できます。

2. **ドラッグでどこでも自由に移動**
   - 時計盤面のどこをつかんでも、マウス左ドラッグでデスクトップ上の好きな場所へ滑らかに移動できます。

3. **起動時に自動で前回の場所・サイズを復元**
   - 終了時のウィンドウ位置（X, Y）やサイズ（幅, 高さ）、選択したタイムゾーン、テーマなどの設定が `clock_settings.ini` に自動保存されます。
   - 次回起動時に自動で前回の場所に完全復元されます。マルチモニターの接続解除時でも画面外に取り残されない安全ガード付きです。

4. **タイムゾーンの変更に対応**
   - **主要タイムゾーンの即時切替**: 右クリックメニューから「東京 (JST)」「UTC」「ロンドン (GMT/BST)」「ニューヨーク (EST/EDT)」「ロサンゼルス (PST/PDT)」「パリ (CET/CEST)」「シドニー (AEST/AEDT)」などを瞬時に切り替え可能。
   - **全タイムゾーン対応ダイアログ**: 「その他のタイムゾーンを選択...」ダイアログから、Windows に登録されているすべてのタイムゾーン（140以上）を検索・現地時刻プレビュー付きで選択できます。
   - **夏時間 (DST) 自動対応**: Windows の `DYNAMIC_TIME_ZONE_INFORMATION` に基づき、夏時間も自動的に正確に計算されます。

5. **その他の充実したカスタマイズ機能**
   - **スムーズ秒針（スイープ運針）**: 1秒ごとにカチカチ動くステップ運針と、機械式時計のように滑らかに連続回転するスイープ運針を右クリックで切り替え可能。
   - **カラーテーマ**: 「ダークモダン」「ライトエレガント」「クラシックゴールド」「サイバーシアン」の4種類を搭載。
   - **常に最前面に表示**: 他の作業中も時計を常に手前に置いておくことができます。
   - **日付・デジタル時刻の表示切替**: 盤面の日付窓やデジタル時計表示を好みに合わせてON/OFF可能。
   - **円形ウィジェット／通常ウィンドウ枠の切替**: デスクトップに浮かぶ円形ウィジェットとしても、タイトルバー付きの通常ウィンドウとしても使用できます。

## 🛠️ Visual Studio でのビルド方法

1. **ソリューションを開く**
   - `AnalogClock.sln` を Visual Studio 2022 で開きます。
2. **ビルド**
   - ツールバーで `Release` および `x64`（または `Win32`）を選択し、`Ctrl + Shift + B` または「ビルド」メニューから「ソリューションのビルド」を実行します。
3. **実行**
   - `F5` または `Ctrl + F5` で実行します。
   - 成果物は `x64\Release\AnalogClock.exe` に生成されます。単体でそのまま配布・起動可能です。

## 📁 ソースコード構成

- [`main.cpp`](main.cpp): エントリポイント (`wWinMain`)、GDI+ 初期化、メッセージループ
- [`ClockWindow.h`](ClockWindow.h) / [`ClockWindow.cpp`](ClockWindow.cpp): ウィンドウ作成、ドラッグ移動、リサイズ、マウスホイール処理、右クリックメニュー
- [`ClockRenderer.h`](ClockRenderer.h) / [`ClockRenderer.cpp`](ClockRenderer.cpp): GDI+ による高品質レンダリングエンジン（アンチエイリアス、針のドロップシャドウ、目盛り、テーマカラー）
- [`TimeZoneManager.h`](TimeZoneManager.h) / [`TimeZoneManager.cpp`](TimeZoneManager.cpp): Windows Dynamic TimeZone API を用いたタイムゾーン列挙・高精度時刻変換
- [`TimeZoneDialog.h`](TimeZoneDialog.h) / [`TimeZoneDialog.cpp`](TimeZoneDialog.cpp): 検索・リアルタイムプレビュー付きタイムゾーン選択ダイアログ
- [`Settings.h`](Settings.h) / [`Settings.cpp`](Settings.cpp): INIファイル形式による位置・サイズ・設定の永続化と画面外安全補正
- [`resource.h`](resource.h) / [`AnalogClock.rc`](AnalogClock.rc): ダイアログおよびアプリアイコンリソース
